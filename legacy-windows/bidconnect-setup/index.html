What Peter sets up, in order

Every account is created with a Legacy business email and paid on a Legacy card, then Levi is invited in. No shared logins.

Each step has links to the exact pages, and two prompts. Copy the Claude in Chrome prompt if you want Claude to walk you through it on screen; copy the Claude Code prompt if you want it done from your PC. Tick Done when the item at the bottom of the card has been sent to Levi.

  6. 
        
    Microsoft sign-in (SSO)Included with Microsoft 365
    
        
        Invite Levi into Legacy's Microsoft Entra as a guest and give him the Application Administrator role. Levi has no way into your Microsoft 365 until you do this. He then registers the app and switches sign-in to Microsoft, limited to Legacy accounts.
        What you get: one login for everyone, Authenticator for MFA, and offboarding is disabling one account. Field crew get a free account in the directory; a paid licence is only needed for email, Teams or Office. One catch: an unlicensed user cannot reset a forgotten password themselves, so you reset it from the admin centre. Test one field account first.
        
    Open:
          Microsoft Entra admin centre (Users > New user > Invite external user; then Roles & admins > Application Administrator > Add assignment) ·
          Microsoft 365 users (add a test field user with no licence) ·
          Supabase sign-in providers (where Levi switches on Microsoft)
