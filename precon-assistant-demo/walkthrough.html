What the assistant did, step by step
1
Step one
Set up the project
What it did
Read the bid details and created the project's folders automatically — no manual setup.
What it created
A tidy, standard project shell — Drawings · Specs · Reports · Scope · Pricing Requests · Vendor Quotes — plus a project info sheet. The same clean setup every time.
2
Step two
Get the files ready
What it did
Unzipped, sorted, and renamed all 23 documents to one consistent style; checked each drawing's title block for its revision; and located the sheet index on 6 of the 8 sets.
What it created
A document list showing every file and what it is — and, the key part, an up-front estimate of what a deep read of the whole package would cost:
~$20 via API· $0 extra if run on an existing Claude seat · vs. a full day of an estimator's time
3
Step three
Read the package
What it did
Read the landscape, civil, specifications, and consultant reports, and drafted four short summaries for the estimator to review.
What it created
Four ready-to-review starting points:
Package summary Scope list · 22 items Issues list · 15 findings Pricing-request plan · 12 vendors
Flagged Issues it caught (easy to miss)
  • No landscape specification was included in the document set.
  • The civil drawings were only a single preliminary sheet.
  • The cash-allowance list was left blank.
  • The site will need dewatering — groundwater sits above the dig level.
  • All 16 protected trees on site are marked for removal.
The bottom line
What normally takes an estimator the better part of a day — sorting, naming, reading, and flagging — the assistant did in minutes — about $20 via API, or $0 extra on an existing Claude seat, and handed back a checked-over starting point. The estimator still makes every final call.
